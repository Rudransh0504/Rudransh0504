### 📄 Academic Paper Intelligence Platform
A research assistant that ingests academic PDFs and answers questions **with citations**, not a basic "chat with PDF."

| Feature | Details |
|---|---|
| 🔎 **Hybrid retrieval** | BM25 + vector search + cross-encoder reranking |
| 📎 **Citation-grounded Q&A** | Answers point back to the source chunks |
| 🧪 **Real evaluation** | Hand-reviewed question set, Recall@K, MRR, vector vs BM25 vs hybrid vs hybrid+rerank |
| ⚙️ **Stack** | Python · FastAPI · PyMuPDF · Sentence Transformers · FAISS |

### 🎬 Cinephiles
A full-stack movie app with an actual recommender behind it.

- 🔐 JWT auth, per-user watchlist & watched tracking

- 🤖 **Recommendation engine**: TF-IDF content-based → ALS matrix factorization → hybrid blend
- 🗄️ FastAPI + Supabase PostgreSQL, TMDB API behind a backend proxy
- 📊 Evaluated against baselines, **with honest numbers** (popularity is a stubborn baseline!)
